## 1. Task 1：四个接口缺陷的修复

### 1.1 掩膜配准从「沿用首株样本」改为「每个样本独立测定」

**Stage 4A 的做法**：`prepare_paa.py` 里有一张写死的表

```python
DEFAULT_CROPS = {0: (16, 24), 1: (440, 80)}   # 在 Broccoli/20260327-10 上测得
```

新样本默认沿用它，只有加 `--reuse-crop` 才会复测。这是跨样本泄漏：另一株植物
只要相机取景偏移了，掩膜就会**静默**按第一株的偏移去裁。

**本阶段实测发现：整数裁剪这个模型本身就是错的。**
`Cotton/1` 的 camera 1 帧是 **3858×2136**，而它的掩膜画布是 **3840×2160** ——
相机帧比掩膜还宽，**不存在裁剪关系**。Stage 4A 的 `matchTemplate` 对这 36 张
全部报 "whitebg frame smaller than the camera frame"，即整台相机无法配准。

**改为逐轴缩放 + 平移的相似变换**（`alignment.match_similarity`）：
ORB 特征匹配 → RANSAC 单应作为外点门限 → 在内点上做**受约束最小二乘**
（只允许逐轴缩放与平移，不允许旋转）。旋转项被排除是因为 PAA 的四路视图之间
只有缩放与平移，放开旋转只会让噪声拟出一个并不存在的倾斜。

**这个估计器自带校验**：在 `Broccoli/20260402-10` 上，相机帧与 whitebg 是**同一批
2160×3840 像素**，估计器返回 `sx = sy = 0.999999`、`tx = ty = 0.00` ——
单位阵到小数点后五位。四个样本的实测值：

| 样本 / 相机 | sx | sy | tx | ty | 拟合残差 (px) | 内点数 | 跨帧 ty 离散 |
|---|---|---|---|---|---|---|---|
| Broccoli/20260327-10 cam0 | 1.00123 | 1.00246 | 14.46 | 14.30 | 1.20 | ≥2154 | 4.29 |
| Broccoli/20260327-10 cam1 | 0.99662 | 0.99743 | 441.65 | 78.23 | 1.17 | ≥2777 | 0.35 |
| Broccoli/20260327-5 cam0 | 1.00051 | 1.00430 | 10.37 | 3.90 | 1.18 | ≥2567 | 3.86 |
| Broccoli/20260327-5 cam1 | 0.99847 | 0.99952 | 238.61 | 54.56 | 0.96 | ≥2839 | 0.12 |
| **Broccoli/20260402-10 cam0** | **1.00000** | **1.00000** | **0.00** | **0.00** | **0.06** | ≥3486 | 0.01 |
| Cotton/1 cam0 | 1.00033 | 1.00170 | 7.56 | 24.60 | 1.20 | ≥1922 | 1.76 |
| **Cotton/1 cam1** | **1.00161** | **1.00115** | **-1.69** | **9.83** | **0.90** | ≥2687 | 0.74 |

**放弃裁剪模型后的收益**：三个新样本的掩膜全部成功配准，其中两个是旧模型
**根本无法处理**的（`Cotton/1` cam1、`Broccoli/20260402-10` 的畸变相机）。

新门限（`prepare_paa.resolve_transforms`）：内点数 < 200 或拟合残差 > 3 px 即拒绝；
**跨帧离散只记录不拒绝**，因为 `Broccoli/20260327-5` 的 per-frame `ty` 跨度达 14.6 px，
但这是 ORB 在不同帧上匹配到不同点集所致 —— 用**逐帧**变换还是**逐相机**变换，
最终掩膜与图像的 IoU 差异 < 0.001（实测），真正该把关的是端到端 warp 检查。

### 1.2 畸变相机：`Broccoli/20260402-10` 的 FULL_OPENCV

Stage 4A 遇到 `FULL_OPENCV` 直接中止（`trainer_ready_without_undistortion=False`）。
本阶段新增支持：

| 项 | 实测值 |
|---|---|
| 相机模型 | FULL_OPENCV，单相机 2160×3840，102 帧全部在 cam0 |
| 畸变系数 | k1 = −0.0684, k2 = 13.97, p1 = −0.0039, p2 = −0.00056, k3 = −181.46 |
| 畸变幅度 | 中心 0 px，四角 14–24 px，69,266 个稀疏点上的平均位移 **0.8 px** |
| 处理方式 | `cv2.initUndistortRectifyMap`，**图像与其掩膜用同一张重映射表** |
| 关键点 | 只整流图像会移动每个像素却把掩膜留在原处 —— 配准就断了，而且**不会报错**，只会训出错轮廓 |
| 源样本 | **未改动**。整流只发生在内存中 |

`colmap_check.py` 的重投影误差计算也同步改为**计入畸变**（`FULL_OPENCV` 用
`cv2.projectPoints`），否则该样本会报出一个虚高且无意义的误差。

### 1.3 端到端配准门限：从「单帧最低值」改为「直接配准度量」

Stage 4A 的门限是「每帧 SfM 点落在掩膜内的比例 ≥ 0.80」。这个度量**不是配准检验**：

`Broccoli/20260402-10` 的第 101 帧只得分 0.759，会被旧门限判为配准失败。但实测：
该帧的掩膜与图像 IoU = **0.985**，位姿重投影误差中位数 **0.473 px**（比样本均值还好），
掩膜包围盒与非白像素包围盒相差 ≤ 8 px。原因是该帧沿标本的细长方向拍摄，
轮廓只占画面 13%（其余帧是 24–38%），而稀疏点云含非标本点（其范围达 13×8×16
世界单位，而标本本身约 2 单位），这些点在多数视角落在轮廓内、在这一视角落在白背景上。

**改为两个直接度量**：

1. **掩膜 vs 图像 IoU**（直接配准检验，与三维无关）——门限 0.80。
   本阶段四个样本的实测每帧最低值为 0.873（`Cotton/1` cam0，白色棉花本体
   与白背景难以用「非白」阈值分开）到 0.963；错配的帧会在 0.5 以下。
2. **SfM 命中率相对样本中位数的比值**（捕捉「这一帧和邻居不一样」）——门限 0.50。

bbox / 质心位移也计算并记录，但**不作为门限**：单个暗像素就能把 min/max 包围盒
推歪几百像素（`Cotton/1` cam1 曾因此报出 173 px 的假误差）。

### 1.4 `run_paa_pilot.sh`：拆分环境 + 按阶段可恢复

- **两个解释器**：`PY_GS`（gsplat 训练/导出）与 `PY_JEPA`（Gaussian-JEPA 前向/反向，

  `splats.pt`（训练完成后选优前崩溃），**重新进入训练器**而不是去猜。
  导出步骤用 mtime 判断是否比 checkpoint 新。
- 登记步骤改为幂等 upsert（§1.5）。

### 1.5 Registry：同一采集不重复登记

`Registry.append`（追加）改为 `Registry.upsert`（按 `crop/acquisition_id` 幂等）。

### 3.1 PAA 掩膜覆盖的到底是什么（Stage 4A 结论的复核）

PAA 的 `RGB_seg/masks` 覆盖**整套标本**：植株 + 花盆 + 土壤 + 支架。
因此纯植物资产必须另做语义分离。

**但颜色在这批数据上帮不上忙。** 本阶段的实测：这株西兰花是**青绿色**，
植株像素的均值为 RGB ≈ (59, 93, 93) —— 蓝通道与绿通道几乎相等。

| 判据 | 在掩膜内的占比 |
|---|---|
| 严格绿 `g>r+15 且 g>b+15` | **0.019**（frame 1）/ 0.234（frame 100） |
| 蓝 `b>r+25 且 b>g+15`（本意是花盆） | 0.803 / 0.179 |
| 植株像素中「绿ish」比例 | 0.87–0.96 |
| 植株像素中「bluish」比例 | 0.69–0.81 |

即：**植株与花盆的颜色区间重叠**，任何纯颜色判据都会把二者搞混。
这既解释了为什么 Stage 4A 的「按颜色分区」只能给出互不排斥的占比，
也说明本阶段必须用真正的语义模型。

### 3.2 两条独立的后端

| 后端 | 模型 | 训练方式 | 类别来源 |
|---|---|---|---|
| `segformer` | `nvidia/segformer-b5-finetuned-ade-640-640` | **有监督**（ADE20K 150 类） | `plant`(17) `flower`(66) → 植株；`pot`(125) `vase`(135) → 花盆；`earth`(13) → 土壤 |
| `sam_clip` | SAM ViT-H（SA-1B）+ `openai/clip-vit-base-patch32` | SAM 有监督 + CLIP **零样本文本提示** | SAM 出区域边界，CLIP 出类别 |

两者性质不同、训练数据不同，因此它们的**一致性**是独立证据。

**实测覆盖率（102 帧平均，掩膜内）**：

| 后端 | 植株 | 花盆 | 土壤 | 支架 | 其余（背景/其它 ADE 类） |
|---|---|---|---|---|---|
| segformer | 0.306 | 0.265 | 0.000 | 0.000 | 0.429 |
| sam_clip | 0.164 | 0.330 | 0.096 | 0.362 | 0.048 |

> SegFormer 的 0.429 主要是它判成 ADE20K 其它类别（如 `chair`、`wall`）的像素，
> 按本模块的映射一律落回背景类 —— 这也正是不能只用一个后端的原因。

**两后端在植株类上的 IoU 中位数 = 0.534**（逐帧记录于
`semantic/agreement.json`）。交集占两者植株像素并集的 **53.2%**；
`plant_only_plant_dir`（仅 SegFormer 认为植株）596.8 万像素，
`plant_only_other_dir`（仅 SAM+CLIP 认为植株）仅 5.3 万像素。

**几何一致性检查**（不依赖颜色，也不依赖人眼）：花盆是底部的容器，植株冠层在其上方。
在每一帧、每一个后端上，植株类的相对竖直重心都在 0.18–0.19，花盆在 0.45–0.66。
两个互不相关的模型在 102 帧上都给出「植株在上、花盆在下」，这是标签有效的
独立证据。

### 3.3 合并规则

植物类取**两后端交集**（保守）：只有两个模型都认为是植株的像素才进入植物类；
花盆/土壤/支架取自 `sam_clip`（ADE20K 没有「支架」这一类）。
未达成一致的像素**弃权**（标为未分类），而不是被强行归类 —— 错误的植物标签
会把花盆送进纯植物资产，错误的花盆标签只是少留一点非植物。

产物：`semantic/labels_merged/`（102 张）、`semantic/merge_summary.json`。

### 3.4 三维关联：可见性加权投票

把逐像素语义提升到三维时，**不能**只做投影：花盆上被植株挡住的点在每一个
视角都落在植株轮廓内。分离必须是**可见性感知**的（与既有
`agri/plant_gs/extract_plant.py` 同一套防御）：

1. 用训练好的高斯渲染每帧的**期望深度**（`RGB+ED`）。
2. 每个高斯投影到每帧，只有当它**就是最前面的表面**时才计一票
   （深度与渲染深度相符，且该像素 alpha 实体）。
3. 可见观测投票该位置的语义类别；类别取多数票，置信度为多数票占比。

被植株挡住的点从来不是最前面的表面，因此**收不到任何证据**。

**结果**（在交付的 `final/point_cloud.ply` 的 292,517 个高斯上）：

**多数票类别**（`classes`，五类互斥，合计 292,498）：

| 类别 | 高斯数 | 占比 |
|---|---|---|
| 植株 | 85,099 | 29.1% |
| 花盆 | 92,853 | 31.7% |
| 支架 | 60,776 | 20.8% |
| 背景 | 53,747 | 18.4% |
| 土壤 | 23 | 0.008% |
| 证据不足（可见票 < 3，`classes = -1`） | 19 | 0.006% |
| **合计** | **292,517** | **100%** |

**雕刻决策**（与上表的类别统计**不是同一口径**，不应相加）：

| 决策 | 高斯数 | 占比 | 说明 |
|---|---|---|---|
| 保留为植株 | 83,810 | 28.7% | 类别=植株，且植株投票占比 ≥ 0.5、σ(opacity) ≥ 0.01 |
| 判为非植物（丢弃） | 206,553 | 70.6% | 类别≠植株，且植株投票占比 < 0.5、opacity ≥ 0.01 |
| 无法判定（丢弃） | 2,154 | 0.7% | 类别=植株但票占比或 opacity 不达标，或类别≠植株但票占比 ≥ 0.5（**与上表有重叠**） |

「保留为植株」83,810 比类别为植株的 85,099 少 1,289 —— 这 1,289 个
高斯可见票里植株是多数，但没达到 0.5 的票占比门槛，按保守原则丢弃
（`retention.plant_gaussians_dropped_for_low_plant_fraction`）。
**保留侧无一个非植物高斯**（`nonplant_kept_of_labelled_nonplant = 0.0`）。

### 3.5 纯植物资产与定量对比

三种资产，用**同一把尺子**（`labels_merged` 的植株区域）评分：

| 资产 | 高斯数 | 植株区 PSNR | 轮廓 IoU vs 植株区 | 植株区覆盖 | 区域外残留 alpha | 区域外不透明比例 |
|---|---|---|---|---|---|---|
| **A** Full-specimen（参考，未分离） | 292,517 | **21.58 dB** | — | — | — | — |
| **B** 从 Full 雕刻（merged 标签） | **83,810** | 17.83 dB | 0.666 | 0.903 | 0.058 | 0.056 |
| **C** 从 Full 雕刻（segformer 标签） | 129,951 | 21.28 dB | 0.487 | 0.992 | 0.182 | 0.179 |
| **D** 在纯植物掩膜下**重新优化** 3DGS | 167,195 | 14.10 dB | 0.632 | 0.765 | **0.029** | **0.029** |

- **植物保留率**：被判定为植株的高斯里 **98.5%** 被保留（另 1,289 个因
  植株投票占比 < 0.5 被丢弃）。
- **非植物残留率**：被保留的高斯中，**非植物类别的高斯占比 = 0.0**
  （定义上就是纯植物资产）；更有意义的是**像素级残留** —— 见上表「区域外残留 alpha」：
  纯植物渲染在植株区域**之外**的平均 alpha 为 0.058，不透明像素比例 5.6%。
  即纯植物资产仍会在轮廓外渲染出约 5.6% 的实心像素（主要来自花盆边缘与支架）。

### 3.6 视觉证据

`semantic/plant_reference_panel/`：**12 个视角**，按相机中心的方位角沿轨道均匀选取
（不是随机），每行三列 —— 原图 / 候选标签着色 / 植株-其它二值图，附
`contact_sheet.jpg` 与 `panel_summary.json`。

视觉复核（Agnes 3.0 Flash，本机无内置视觉能力）逐行结论：绿色块落在真正的
茎/叶/花球上，红色区域覆盖花盆、支架与土壤；**仅在俯视视角发现一小片土壤被
误标为植株**，其余视角无明显错标。

> 该视觉描述仅作旁证。与数值一致时作为确认；一旦与逐像素统计冲突，**以数值为准**
> （Stage 4A 已有先例：视觉模型曾给出与像素统计相反的结论）。

### 3.7 「重新优化 vs 雕刻」的取舍（基于证据的选择）

| | B：从 Full 雕刻 | D：在纯植物掩膜下重新优化 |
|---|---|---|
| 植株区 PSNR | **17.83 dB** | 14.10 dB |
| 植株区覆盖 | **0.903** | 0.765 |
| 区域外残留 | 0.058 | **0.029** |
| 额外训练成本 | **0** | 30k 步 ≈ 11 分钟 + 数据准备 |
| 高斯数 | 83,810 | 167,195（D 多一倍） |

**结论：选雕刻，不选重新优化。** 理由是证据上的：
重新优化确实把区域外残留压到一半（0.029 vs 0.058），因为它从没见过花盆；
但它在**植株本体上更差**（PSNR 低 3.7 dB，覆盖率低 14 个百分点），
而且高斯数多一倍 —— 在掩膜没有监督到的细茎与遮挡区域，它重建不出东西。
雕刻保留了 Full-specimen 优化中已经学到的植物几何，代价是残留约 5.6%。

**前提**：这个结论依赖候选掩膜的质量。D 与 B 用的是同一套候选掩膜，
因此两者之差是**方法之差**；但「哪个掩膜更好」这一问题，由 §3.2/§3.3 的一致性
与几何检查回答，不由本节回答。

### 3.8 明确不成立的结论

- 没有可信的人工标注，因此**没有分割准确率**。本节所有数字都是
  **与候选掩膜的一致性**。
- 植株/花盆/支架的语义来自**零样本 / 域外**模型，不是为农业训练的分割器。
- 分离只在**单个样本**上验证过。跨植株的泛化未验证。

### 4.1 采样 1,024 个高斯后的语义构成

Full-specimen 资产的**总体**构成（292,517 个高斯）与**均匀采样**（1,024 个，
8 个种子的均值 ± 标准差）：

| 类别 | 总体占比 | 均匀采样占比（8 种子均值） | 标准差 |
|---|---|---|---|
| 植株 | 0.2909 | **0.2870** | 0.0101 |
| 花盆 | 0.3174 | **0.3179** | 0.0120 |
| 支架 | 0.2078 | **0.2150** | 0.0070 |
| 背景 | 0.1837 | 0.1895 | — |
| 土壤 | 0.0001 | 0.0001 | 0.0003 |
| 无法判定（`classes = -1`） | 0.00006 | — | — |

**均匀采样在语义构成上是无偏的**（与总体构成一致到 1 个百分点内）。
这意味着：**用官方采样器从 Full-specimen 资产取 1,024 个高斯，其中约 71% 不是植物**
（8 种子均值 1 − 0.2870 = **71.3%**）。

Pure-plant 资产的采样构成是 100% 植株（按构造）—— 它的 83,810 个高斯全部
来自上表的「植株」类，因此这条对比只说明「纯植物资产把输入强制限定在植物上」，
不说明「分割有多准」。

### 4.2 极小尺度高斯的被采样频率

采样分析用的是**每个高斯三条轴中的最大值**（一个高斯有多大，由它最长的那条轴决定）：

| 项 | 数值 |
|---|---|
| 总体最大轴尺度中位数 | 8.140e-03 |
| 总体 p05 / p95 | 2.378e-03 / 3.232e-02 |
| **总体中「最大轴 < 1e-6」的比例** | **0.0000** |
| 均匀样本中「最大轴 < 1e-6」的比例 | 0.0000 |
| 均匀样本尺度中位数 | 8.471e-03（总体 8.140e-03） |

**没有一个高斯整体退化到最大轴都低于 1e-6**，所以过采样比无法定义（分子分母
都是 0，报告为 `null`）。这同时说明两件事：这批资产的质量是好的（没有塌缩到
奇点的高斯），以及**「JEPA 均匀采样会过采样极小高斯」这个担心在当前资产上
不成立** —— 均匀采样按行等概率，对尺度天然无偏，实测样本与总体的尺度中位数
只差 4%。

需要区分的是另一件事：**压扁的高斯**（至少一条轴 < 1e-6）确实存在，
在四个交付资产上的比例为：

| 资产 | 至少一轴 < 1e-6 | 三轴均 < 1e-6 |
|---|---|---|
| Broccoli/20260327-10 | 9,867（3.37%） | 0 |
| Broccoli/20260402-10 | 6,250（2.03%） | 0 |
| Broccoli/20260327-5 | 21,723（7.19%） | 0 |
| Cotton/1 | 22,821（7.12%） | 0 |

这类高斯在空间中是一个「薄片」，可见面积很小，渲染贡献有限。这是**资产本身
的性质，不是采样器引入的偏置**（§4.1 的语义构成同样无偏）。若下游对压扁
高斯敏感（例如需要可靠法向或体积估计），应按**最小轴**而不是最大轴重新统计；
本阶段只给出总体规模，不做下游结论。

|---|---|---|---|

### 4.4 均匀采样 vs 结构均衡采样

结构均衡采样器（`sampling_analysis.sample_balanced`）在 32³ 晶格的每个占据
体素至多取一点，剩余名额从已选点之外补齐。

| | 均匀（官方） | 结构均衡 |
|---|---|---|
| 空间覆盖（16³ 体素） | 0.296 | **0.426**（+44%） |
| 最近邻距离中位数 | 0.038 | **0.065**（点更分散） |
| 半径分布 | 贴合总体 | **更靠外**（0.750 vs 0.618） |
| 植株占比（8 种子均值） | 0.287 | 0.133 |

**取舍**：均衡采样用 **空间覆盖**换 **语义均衡**。它覆盖了多 44% 的空间，
但植株占比从 28.7% 掉到 13.3%，因为支撑结构占据了大量体素。
对农业预训练而言，「冠层在每个视角都被看到」与「每类都被等量看到」是两回事，
本阶段**不改动官方采样器**；这里给出的是代价的量化，供后续决定。

> 顺带修掉一个真实 bug：均衡采样器补齐名额时会把已选点再抽一次，
> 导致返回的索引集**悄悄变小**（实测 1,024 → 972）。已修并加测试锁定。

### 6.2 风险清单（按严重度）

1. **语义分离未跨样本验证。** 纯植物资产目前只有一个样本的证据。
   `Cotton/1` 是**白色**植株（`sam_clip` 在其上把大片棉花标为「支架」），
   说明零样本模型的失效模式与作物强相关。**扩展到 41 组前，至少要在
   3–4 个不同作物上跑一遍语义分离并人工检查参考面板。**
2. **相机模型只覆盖 2 种。** 代码支持 5 种，但真实数据只出现过 2 种。
   剩余 37 组里若出现 `SIMPLE_RADIAL` / `RADIAL` / `OPENCV`，会走同一条整流路径，
   但**没有在真实数据上验证过**。
3. **单相机 vs 双相机。** `Broccoli/20260402-10` 是单相机 102 帧；
   其余是双相机（99+3 或 66+36）。统一画布策略对「少数派方向」的处理已被
   两种比例（3/102 与 36/102）验证过。
4. **计算成本。** 每个样本 ≈ prepare 70–90 s + 30k 训练 630–750 s + 导出/校验
   ≈ 60 s ≈ **13–15 分钟**（单卡 A6000）。41 组 ≈ **9–10 小时**单卡，
   两卡并行 ≈ **5 小时**。数据下载另需 41 × 约 150 MB ≈ **6 GB**。
5. **磁盘。** 单样本实测（`Broccoli/20260402-10`，含 7k + 30k 两轮 checkpoint）：

   | 目录 | 体积 |
   |---|---|
   | `results/`（两轮训练 checkpoint） | **1.2 GB** |
   | `final/`（PLY + 渲染） | 151 MB |
   | `dataset/`（帧 + 掩膜） | 18 MB |
   | **单样本合计** | **约 1.3 GB** |

   若只保留 30k 一轮（不跑 7k 试运行），约 **0.9 GB/样本**。
   41 组 ≈ **37 GB**（单轮）或 **53 GB**（双轮）。外部原始数据
   （每个样本约 150 MB）另计：当前 4 个样本为 795 MB，41 组约 **6 GB**。

### 6.3 建议的扩展顺序

**可以安全扩展**，但建议按「先覆盖相机/作物差异，再铺量」的顺序：

1. **先跑 4 个「代表性」样本**：Cabbage/20260328-9（第三个带日期的作物）、
   Tobacco/20260401-23（第四个带日期的作物）、Rice/1（第五个作物）、
   Sunflower/1（第六个作物）。这 4 个样本一次性覆盖了：3 个未跑过的带日期作物、
   3 个未跑过的无日期作物、以及可能的第 3、4 种相机模型。
   **每个样本都要跑语义分离并人工检查参考面板** —— 这是 Task 3 唯一未跨样本验证的环节。
2. 这 4 个通过后，再批量跑完剩余 33 个。
3. 语义分离若在某个作物上失效（如 Cotton 式的白色主体），该作物应先做一次
   掩膜策略的调整，而不是让错的植物掩膜进入资产库。

**数据划分**（41 组规模下）：`split_group = crop/plant_id` 共 23 组。
按植株划分可得到 23 个独立组，足以做「按植株留出」的泛化测试；
Broccoli/Cabbage/Tobacco 的 6 个多日期植株应**整组**留在同一侧。

## 7. 是否已有足够证据决定后续农业预训练的输入形式

### 7.1 目前**没有**证据的事

- 官方 Gaussian-JEPA 预训练 checkpoint 仍不可用（ShapeSplatsV1 未获批）。
  所有 JEPA 数字都是**随机初始化**模型上的工程契约验证。
  三个新样本的 JSON 里都显式写着 `initialization: random`、
  `pretraining_claim: NOT_MADE`、`semantic_effectiveness: NOT_EVALUATED`。
- 因此**没有**任何关于「哪种输入形式能学到农业语义」的证据。
  本阶段测的是**输入数据里有什么**，不是**模型能学到什么**。

### 7.2 已经有证据的输入侧事实

| 事实 | 数值 | 出处 |
|---|---|---|
| Full-specimen 资产的采样中，非植物占比 | **71%** | §4.1 |
| Full-specimen 资产的采样中，植株占比 | **28.7%** | §4.1 |
| 纯植物资产的采样中，植株占比 | **100%** | §4.1 |
| 纯植物资产相对 Full-specimen 的代价 | 植株区 PSNR 21.58 → 17.83 dB，覆盖 0.903，残留 5.6% | §3.5 |
| 两后端语义一致性（植株 IoU） | 中位数 0.534 | §3.2 |
| 均匀采样对语义与尺度均无偏 | 构成差 < 1 个百分点 | §4.1, §4.2 |
| 均衡采样提升空间覆盖 | 0.296 → 0.426 体素 | §4.4 |

### 7.3 结论

**对「用哪种输入形式」的判断：**

1. **如果预训练的目标是植物表型/语义，那么 Full-specimen 资产是不合适的输入**，
   理由是量化的：用官方采样器从它取 1,024 个高斯，**约 71% 不是植物**。
   模型看到的是花盆和支架的形状。
2. **纯植物资产是更合适的输入**，代价明确：植株区 PSNR 降 3.75 dB、覆盖率 90.3%、
   区域外残留 5.6%、高斯数减少 71%。
3. **但这个代价是在「候选掩膜」的质量下测得的。** 若把植株/花盆分得更准，
   代价会更小；分得更差，代价更大。**因此「先改进语义分离」比「现在就决定
   输入形式」更有价值。**
4. **不建议现在就把纯植物资产定为唯一预训练输入。** 理由是 §3.8 的三条限定：
   分离只在 1 个样本上验证过、语义来自零样本/域外模型、没有独立标注可校验。
   **建议**：并行保留两类资产，在 2–3 个作物上把语义分离的跨样本质量补上之后
   再定。当前阶段已经**建立了生产两类资产的完整管线**，这是本阶段的实际产出。

### 7.4 下一步的证据缺口（按优先级）

1. **语义分离的跨样本验证**（3–4 个作物）+ 人工检查参考面板。
   这是唯一挡住「决定输入形式」的缺口。
2. **一个可用的官方预训练 checkpoint**。没有它，任何「哪种输入更好」的
   比较都只能在随机初始化上做，测的是随机性不是表征。
3. **植株/花盆的人工标注**（哪怕 20–50 视角）。有了它，§3 的所有数字才可以
   从「一致性」升级为「准确率」。

## 9. 结论摘要

**做成了什么**

- Task 1 的四个缺陷全部修复，并在此过程中发现**旧配准模型在两类样本上根本不成立**
  （整数裁剪 vs. 相似变换；畸变相机 vs. 整流），修复后三个新样本全部通过。
- 三个新 PAA 样本的完整闭环：COLMAP 审计 → 配准 → 3DGS 30k → PLY 导出 →
  Gaussian-JEPA 读取/前向/反向/优化器探针 → 登记。PSNR 24.48 / 26.13 / 23.88 dB。
- 纯植物资产的**可运行管线**（两套独立语义后端 → 保守合并 → 可见性加权三维
  投票 → PLY 导出 → 区域级评测），以及**12 视角人工可检查参考面板**。
- JEPA 采样分析：官方均匀采样从 Full-specimen 资产取 1,024 个高斯，
  **约 71% 不是植物**；给出与结构均衡采样的量化对比。
- 全 PAA 数据集身份清单：41 采集 / 23 植株 / 6 作物 / 25 天；
  `Broccoli/10` 的两次采集确认同组；跨日期配准**不可用**已明确记录。

**关键量化结论**

| 结论 | 数值 |
|---|---|
| 官方采样中非植物占比（Full-specimen） | 71.3% |
| 纯植物资产相对 Full-specimen 的植株区 PSNR 代价 | 21.58 → 17.83 dB |
| 纯植物资产的非植物残留（像素级） | 5.6% |
| 重新优化 vs 雕刻 | 雕刻胜（PSNR +3.7 dB，覆盖 +14 pt，零额外训练成本） |
| 两后端语义一致性（植株 IoU 中位数） | 0.534 |
| 均衡采样 vs 均匀采样的空间覆盖 | 0.296 → 0.426 |

**本阶段明确没有建立的**

- Gaussian-JEPA 的农业语义预训练（官方 checkpoint 仍不可用）。
- 任何**分割准确率**（PAA 无人工标注；所有数字是候选掩膜的**一致性**）。
- 纯植物分离的**跨样本**泛化（只验证了 1 个样本）。

**是否进入全量 41 组**：可以，但建议先跑 4 个代表性样本
（Cabbage/Tobacco/Rice/Sunflower 各 1），每次都做语义分离 + 人工检查，
把 Task 3 唯一未跨样本验证的环节补上，再批量铺量。

**是否已可决定预训练输入形式**：**尚不充分**。证据支持「Full-specimen 资产中
71% 的采样不是植物，不适合作为面向植物表型的预训练输入」，也支持「纯植物资产
是更合适的输入，代价已量化」；但由于语义分离只在 1 个样本上验证、且无独立标注，
**建议保留两类资产并行，等语义分离跨样本验证后再定**。
